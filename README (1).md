# SMK POS (Offline Burmese POS starter)

A basic offline Android point-of-sale starter app in Burmese.

Features: add/edit/delete products, price and stock, cart, checkout confirmation, sales history, local storage, MMK display.

## Build APK
1. Upload this project to a GitHub repository.
2. Open the **Actions** tab and select **Build SMK POS APK**.
3. Tap **Run workflow**.
4. Once finished, download artifact **SMK-POS-debug-apk**, unzip it, and install `app-debug.apk`.

The APK is a debug build and may show Android's usual sideload warning. This starter is not a Loyverse clone of proprietary assets or code; it implements similar POS concepts in a new app.
